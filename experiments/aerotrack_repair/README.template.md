Review 2 compared two checkpoints on different image sets, ran no ablation, selected checkpoints on a noisy
metric, showed a hand-typed trajectory plot, and captioned a raw-detector demo as "ByteTrack". Every claim below is
now tied to a generated file, evaluated on one fixed image set, with the trivial baselines each component must beat:

| Review-2 claim | What the controlled measurement says | Where |
|---|---|---|
| "+43 % mAP from fine-tuning" | On the same images the drone-class AP moves by about a point; the mAP jump is the bird class. v2 is *below* v1-last on drone AP, CST and Anti-UAV. | detector table below |
| SPD-Conv / temporal stack "empirically verified" | {{ablation_claim}} |

## System

Detector: YOLO11n layout (Ultralytics 8.4) with the five stride-2 downsampling convolutions replaced by
space-to-depth convolutions (`src/model/yolo11-spd.yaml`, `custom_modules.SPDConv`), taking a 9-channel input made of
frames *t−1, t, t+1* letterboxed to 640×640. COCO-pretrained `yolo11n.pt` initialises every tensor whose name and
shape match (the SPD stems, the class head and — with the installed Ultralytics, whose C3k2 bottlenecks use a 1×1 `cv1`
where the checkpoint has 3×3 — those `cv1` convolutions start from scratch). Two classes: `uav_drone`, `bird_hard_negative`.

Components that were evaluated and **retired** by pre-registered rules (kept in the repo for the record):
`src/model/bytetrack.py` (tracking) and `src/model/lstm_forecaster.py` (forecasting) — see the tables below.

## Data

Three sources, standardised by `src/pipeline/` into a unified YOLO corpus: Anti-UAV (318 IR/RGB sequence pairs,
593,802 frames), CST Anti-UAV (144 IR sequences, 162,187 frames, recovered from a truncated archive), Det-Fly (7,830
daylight images with `Bird`/`Drone` labels). Splits are **sequence-level** (`data/derived/data_unified/splits.json`,
seed 1337, leakage assertions in `src/pipeline/3_prepare_training.py`); CST ships no val split, so a fixed-seed holdout is
carved from its train split and CST-test is never used for selection. Training samples 25,000 frames per epoch with a
hardness-aware weighted sampler.
