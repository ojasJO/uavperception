MODEL STATISTICS (both research directions)
============================================================
Compiled 2026-10-26 from the workspace registry and the run reports. Nothing here was re-run: every number is
copied from a recorded result, and each section names its source file (paths relative to the repo root).

  registry/models.json          every checkpoint identity (SHA-256, status, architecture, training data)
  registry/experiments.jsonl    317 recorded results (training ledger, VAL / TEST evaluations, paper numbers)
  model_benchmark/logs/         copies of all training / evaluation / job logs (index: model_benchmark/LOG_INDEX.csv)

Metric glossary
  mSA            mean state accuracy (%), the Anti-UAV / CST tracking score: IoU on frames where the target is
                 visible, plus credit for correctly reporting "absent" when it is not. Higher is better.
  success AUC    area under the IoU-threshold success curve (%).
  precision@20   % of frames whose predicted centre is within 20 px of ground truth.
  AP50 / mAP50   detection average precision at IoU 0.5 (0-1). "drone AP50" = drone class only.
  ADE px         average displacement error of a trajectory forecast, in pixels. Lower is better.
  VAL / TEST     validation split (used for every decision) / held-out test split (used only in registered passes).
  last.pt        the checkpoint every evaluation uses (fixed before any run; fitness-selected best.pt is not used).

2. MODEL SPECIFICATIONS
-----------------------
Direction A detector (all AeroTrack detector families)
  architecture     YOLO11n "as-built" (stride layout, c3k=True), 2,604,918 parameters, 6.7 GFLOPs (fused)
  input            3 frames stacked into 9 channels, letterbox 640x640; window per run, e.g.
                   causal_g4 = [t-8, t-4, t], stock = [t, t, t] (single frame), sym_g4 = [t-4, t, t+4]
  output           detections -> STE single-target state estimator (Kalman-style) -> one box or "absent" per frame
  framework        PyTorch + Ultralytics 8.4.115, 20 epochs, COCO-pretrained YOLO11n init
  training data    corpus v2 = Anti-UAV + complete CST + Det-Fly (v2, F1); CST train only, 120 sequences (X1/X2);
                   corpus v1 with truncated CST (generalization, repair, Review 1/2)
  hardware         RTX 5050 Laptop GPU (OMEN) about 1.4-2.5 h per run; X1/X2, F1 and most v2 runs on Amrita HPC

Direction A forecasters (Track C)
  C1   MLP / GRU / transformer history encoder + per-horizon Gaussian head; 16 frames of history -> 24 future
       frames (mean centre + variance per axis); PyTorch on CPU; Anti-UAV IR/RGB + CST training trajectories
  C1c  transformer + Gaussian head; "domtok" = pooled with a camera token, "perdom" = one model per domain
  LSTM retired Review-2 forecaster (c_model/lstm_forecaster.py)

Direction B tracker (Anti-UAV 2021 paper reproduction)
  architecture     GlobalTrack QG-RCNN, ResNet-50-FPN (torchvision re-implementation)
  input            Anti-UAV IR (640x512) or RGB (1920x1080) frames + frame-0 ground-truth box
  output           one box + score per frame (never reports "absent")
  training         18 epochs, batch 2, LR 0.0025 (x0.1 at epochs 12 and 15), init from COCO Faster R-CNN,
                   Anti-UAV train (160 sequences) of the run's modality; about 2.0-2.5 h per run on the RTX 5050
  variants         normal = standard training; DFSC = the paper's proposed dynamic feature selection

three direction folders:
